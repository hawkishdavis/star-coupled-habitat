# Star-Coupled Habitat

A rotating space habitat concept by Hawk Davis, and one open question for a geometer.

Not a flat disk. A cage within a cage: rings in different planes, held in magnetic suspension, each drawing spin from one outer driver ring. Gravity by rotation is textbook. The open problem is what the tilted rings do to each other.

- `index.html`: an interactive model. Drag to orbit, set spin rate and radius, switch between the cage and coplanar rings, let precession loose and watch the attentive governor try to hold it. The readouts use the paper's own formula, g = ω²r.
- `paper.md`: the concept paper, v0.2 draft, July 2026, with two external reviews folded in and every claim labeled EMPIRICAL, EXPERIMENTAL, or ASPIRATIONAL.

## The question

Rings spinning in different planes each carry an angular momentum vector pointing a different way. Couple them, or nudge one, and each answers by twisting perpendicular to the push. Can the field geometry be arranged so a set of non-coplanar levitated rings stays put, or does every arrangement pay for stability with continuous power?

## Status

Concept, not engineering. Nothing here is a claim of buildability. Spin gravity, magnetic bearings, and flywheel storage are established. The star-topology coupling is unmodeled at habitat scale. The non-coplanar cage and rings-as-shield are aspirational and say so.
